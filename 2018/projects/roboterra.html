RoboTerra: Redesign the public website.

About the company

RoboTerra is a robotic educational company. They use an innovation way and provide robotic kits and an online learning platform service to teach kids about robot, math, physical, programming and design.

Timeline

May. 2015 to Aug. 2015

Project Detail

Group project

My Role

Wireframe, User interface, visual design, design guideline(HTML,CSS)

CONTEXT
I joined the team to redesign their public website (Chinese version). Working with project manager and software engineers, my main focus was to improve the user experience of their current website, create the new visual direction, as well as implement the style guide for multiple web pages.

UX DESIGN PROCESS

Identify the pain points

Working with project manager and marketing members, we summed up several users' pain points based on their feedbacks.

Users’ main pain points

  • People are not clear about what RoboTerra does
  • Less information about the course
  • People don't know where to register the class
  • The current interface isn't mobile friendly.

Wireframes for web pages

I, then, worked with the project manager and started with the website navigation. Based on the users' pain points, I created the first version of low-fi wireframes for web pages.

Website navigation card sorting and sketch wireframes

The team and I noticed that the old version of the website didn't clear explain what RoboTerra is and what user can do on the site. Therefore, at the homepage, we decided to separate into different sections and simply explain the services we can provide for users.

Different layout for homepage

VISUAL DESIGN

Colors for website

When I started to create our visual design, I, at first, needed to decide the main color palette for the whole site. Because RoboTerra's logo contains many colors, I started with picking some colors that can help the identity to pop up. Also create two version of the homepage for the team members to get a feel of what it will look like.

FRONT-END DEVELOPMENT

Design Guideline

Because the project schedule was pretty tight, the engineer team and the design worked almost at the same time. Also, we found that it's hard to keep the layout consistent from different engineers. Hence, I created a simple design guideline by using HTML and CSS for engineers. So that they can directly apply the CSS class without changing the code.
